About This Site

    
This is an experiment.
I wanted to see how far I could take voice as a way of making things, so every part of this site was built by talking it through with Grok Bot, and I never wrote a line of the code by hand.
A few of the voice notes that built it:

    
  • “Portfolios and, you know, CVs are a little fatigued.”
  • “How far can I take this with my voice?”
  • “It needs to be earned, and it needs to be there for a reason.”
  • “How would Steve Jobs think about this?”

    
The type is a bitmap stack and the patterns are 1-bit, after the Apple Human Interface Guidelines from 1987. The board borrows from Are.na and the timeline from pi.website.
